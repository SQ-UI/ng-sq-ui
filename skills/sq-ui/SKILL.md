Read `get_overview` first and match the target Angular and library versions. Use `list_components` for discovery and `get_component_api` for exact inputs, signal models, public types and projected templates. Source snapshots do not prove that a version has been published.

For a focused component, read its runnable example. For a page or application, use `list_blueprints` and `plan_ui`. Build workflows require a registered workspace. Preserve the user's selected framework, branding and task scope.

Route setup, forms, themes, admin composition, migration and validation to the corresponding `sq-ui-*` skill when available. A successful tool response must have `ok: true`; a job is finished only when its status and result confirm completion.
