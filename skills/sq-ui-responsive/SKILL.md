---
name: sq-ui-responsive
description: Validate and repair responsive ng-sq-ui forms, navigation and data layouts.
---

Inspect the generated interface at 320, 390, 768 and 1440 pixels. Use `preview_ui` for screenshots and overflow diagnostics; poll the returned job until it finishes.

Check actual menus and long content, rather than only an empty page. Keep actions and sort/filter controls reachable when desktop tables become cards. Let text wrap and use minimum widths only where content requires scrolling.

Check keyboard focus and touch interaction after each layout repair. Use logical properties when RTL is requested and repeat the same checks in both themes.
