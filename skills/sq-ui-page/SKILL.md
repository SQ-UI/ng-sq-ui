---
name: sq-ui-page
description: Build an ng-sq-ui page from a checked CRUD, dashboard, settings or login recipe.
---

Read `list_blueprints`. Use UiSpec mode `page` with a page blueprint and meaningful title, locale and output directory. For existing applications inspect the workspace and explicitly select the routes and global stylesheet files.

Plan the form, data and loading/empty/error/success states. Generate and apply the changeset. Existing routes are extended through a scoped route; user changes cause a conflict instead of being overwritten.

Validate compilation and the page's important interactions, then inspect mobile and desktop screenshots. The login recipe represents demonstration access with local data.
