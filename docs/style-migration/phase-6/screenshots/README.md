The two reference rows contain cropped component images; the field crop excludes its external spacing. Modals use a 640px-high viewport.

See the [validation report](../../phase-6-validation.md) and [measurement/interaction manifest](manifest.json). The reference images were inspected against cached source screenshots; remaining unread Figma variants are not signed off by this capture.
