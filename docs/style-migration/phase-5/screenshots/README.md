# Phase 5 browser captures

Captured from the real Angular `/#/preview` at 1440px and 390px widths. These 44 screenshots preserve the Phase 4 capture set and add message, template and theme scenarios. Each image is a visible viewport after scrolling to its target; long sections can extend below the image. Modal captures use a 640px viewport height.

Custom-template screenshots show the state after tested interactions: Design selected in the dropdown, one remaining tag, the typeahead selection removed, checkbox disabled in its model, and weekly radio selected. The checkbox remains interactive; “disabled” is the custom label's value description, not a disabled native input.

See the [Phase 5 report](../../phase-5-examples-and-docs.md), [reference checklist](../../preview-reference-checklist.md), and [measurement/interaction manifest](manifest.json). These are local implementation captures, not a completed comparison with unread Figma variants.
