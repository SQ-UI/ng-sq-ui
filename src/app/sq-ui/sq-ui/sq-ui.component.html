Exported Packages Preview:

The preview uses signal-based two-way binding via [(value)] on each form component. On submit, a compatForm() bridge from @angular/forms/signals/compat aggregates the signal values. The final input values are console logged on click of the Submit button.

Every control is standalone and shares the same inputs: name, controlId, controlLabel, controlPlaceholder, required, pattern (an array of RegExp) and disabled, plus a (touch) output when the user leaves the control. That is exactly what the Angular Signal Forms [formField] directive binds, so each control also works with [formField] instead of [(value)].

sq-input

  • [(value)] is a string; [type] sets the native input type (default text).
  • [required] and [pattern] are applied to the native input as validation attributes.

sq-textarea

  • An auto-growing, content-editable text area: [(value)] is a string and keeps line breaks.
  • [minHeight] sets the minimum height in pixels (default 100). When [disabled] it can be neither edited nor focused.

sq-radiobutton + sq-form-group

  • Radio buttons with the same name form a group; each one represents its [radioValue]. Bind the same signal to every radio of the group with [(value)]: it holds the value of the selected radio.
  • (isSelectedChange) reports the selection and the deselection of a radio. A custom label is an ng-template sq-radio-label with the isSelected and value context.
  • sq-form-group is a labelled container ([groupLabel]) for related controls.

sq-dropdown default

  • [options] is a LabelValuePair[]; [(value)] holds a copy of the selected option (or null), and (onSelectItem) emits the option itself.
  • Keyboard: focus the control with Tab, open it with Arrow Down, Enter or Space, move with the arrow keys, select with Enter or Space and close with Escape.

sq-tags-input default

  • [(value)] is a string[]. Space, Enter or a comma adds the typed text as a tag; Backspace in the empty field removes the last tag.

sq-tags-input with a custom tag template

  • The sq-tag template receives the tag and a remove function to call with it.
{{tag}}

sq-typeahead multiple choice with custom templates

  • (onUserInputEnd) emits the typed text once the user stops typing for [delay] ms (default 500). Answer it with a new array in [searchResults], even an empty one: that is what hides the loader.
  • Results can be strings, numbers or objects: [displayProp] names the object property used as the label; without it the objects must already be {{ '{' }} label, value {{ '}' }} pairs.
  • [(value)] is a LabelValuePair[]; [multiple] allows more than one selection and [hideSearchIcon] hides the icon.
  • Custom templates: sq-typeahead-option (context option) and sq-typeahead-selected-option (context item and a remove function).
