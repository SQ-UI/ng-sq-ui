Exported Components Preview:

The preview uses signal-based two-way binding via [(value)]; both pickers also work with the Angular Signal Forms [formField] directive. A value written from outside (for example a form reset) is reflected by the picker. The final input values are console logged on click of the Submit button.

Dates are Temporal objects, imported from the @sq-ui/ng-datetime-picker/temporal entry point (the @js-temporal/polyfill by default; see the README to alias it to a native implementation).

Standalone Datepicker (multiple select enabled)

  • [(value)] holds a Temporal.PlainDate by default; [dateObjectType] switches it to a 'date' (Date) or 'unix' (epoch milliseconds).
  • [isMultipleSelect] selects a period: click a start date, then an end date, and every date in between is selected. The value is the array of all those dates, sorted ascending. While only the start is picked, moving the mouse over the calendar previews the period, the dates before the start cannot be picked as the end, and changing the month or year keeps the start date. Clicking the start date again selects that single day; the next click after a complete period starts a new one.
  • [format] turns the value into a string; the tokens are YYYY, MM, DD and, with the time picker, hh (24-hour), mm and ss. Every occurrence of a token is replaced.
  • [minDate] / [maxDate] (Temporal.PlainDate or Date) disable the dates, months and years outside the range. Browsing months and years keeps the current selection.
  • Other inputs: [locale] (weekday and month names, default 'en') and [disabled]. Outputs: (dateSelectionChange) on every selection and (touch) when focus leaves the picker. Without a value, the picker starts with today selected.

Datepicker (multiple select disabled) + Timepicker (meridiem enabled)

  • [isTimepickerEnabled] adds a time picker; the selected date then becomes a Temporal.PlainDateTime (or is formatted with the time tokens).
  • [timepickerConfig] (TimepickerConfig) sets the initial hours / minutes, the hourStep / minuteStep of the arrows, isMeridiem (12-hour display with AM/PM) and isEditable (typing into the fields). The meridiem setting only changes the display: hh in [format] is always 24-hour.

Standalone Timepicker (meridiem disabled)

  • [(value)] is a string (HH:mm, or hh:mm AM with [isMeridiem]) or, with timeObjectType="plaintime", a Temporal.PlainTime. Both forms are accepted when written from outside; a null value is replaced by the time on display.
  • [hours] / [minutes] set the time, [hourStep] / [minuteStep] the arrow steps, and (hoursChange) / (minutesChange) report arrow changes.
  • [isEditable]="false" (as here) only blocks typing: the arrows still work. [disabled] blocks both. Invalid typed values are corrected when the field loses focus.
