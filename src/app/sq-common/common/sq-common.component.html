Description:

This package exports the common interfaces, contracts, components, directives and services used by the other SQ-UI packages. Every component and directive is standalone: import it directly into your component's imports. Some examples include:

  • The sqOutsideClickListener directive is used to track if the user has clicked outside a specific element. Set [listenForOutsideClick] to true to arm it and handle (clickOutside). It has been applied to the sq-modal component, as well as sq-dropdown and sq-typeahead.
  • The sqScrolledToBottomListener directive is used to track if the user has scrolled to the bottom of a specified container. It emits (scrolledToBottom) only once the user has reached the bottom of the container (with a one-pixel tolerance, so it also works on zoomed and high-DPI screens).
  • The FormFieldConfig / SqFormFieldSignals contract and the FORM_FIELD_DEFAULTS values define the inputs every ng-form-elements control shares (name, controlId, controlLabel, controlPlaceholder, required, pattern, disabled and the (touch) output). Together with the SqFormValueControl / SqFormCheckboxControl / SqFormUiControl aliases they let each control be bound with [(value)] or with the Angular Signal Forms [formField] directive.
  • The InputCoreComponent and ControlValueAccessorEnabler classes are deprecated: they are kept only for backward compatibility with code that still extends them. The form controls no longer use them.
  • The sq-paginator component is used to control the view collection of the sq-datatable component. It takes [items], [itemsPerPage], [currentPage], [lastPage] and [maxDisplayedPages], exposes the visible page through [(paginatedCollection)] and emits (pageChange) with the page number and the index of its first item.
  • The CustomEventBroadcasterService is a root-provided event bus for named events between unrelated components (for example, it keeps only one sq-radiobutton per group selected). Install a single copy of @sq-ui/ng-sq-common next to the other SQ-UI packages so they all share it.

For information on how to apply each specific tool, refer to the documentation.
