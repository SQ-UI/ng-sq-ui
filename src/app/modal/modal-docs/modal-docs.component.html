Exported Components Preview:

  • Visibility is a two-way [(show)] binding: set the bound signal to true to open the modal. A modal whose binding starts as true is shown straight away.
  • Content is projected into three slots: [sq-modal-title], [sq-modal-body] and [sq-modal-footer].
  • The modal closes (and writes false back to the binding) from its close button, a click outside the window or the Escape key.
  • [customCssAnimation] takes {{ '{' }} duration, entranceAnimation, exitAnimation {{ '}' }}; the defaults are 500 ms, fadeInDown and fadeOutUp (bundled with the modal styles). Custom animation names are CSS classes your application provides.
